# Art direction

Working direction: **industrial night shift**. Near-black machine enclosure, warm aluminum, cyan blueprint lines, amber heat, red fault states, condensed technical typography, and minimal diegetic HUD panels.

The machining interaction remains code-rendered for clarity. The Asset Lab extends the same industrial-night-shift language into original Blender geometry: monolithic fictional machine silhouettes, process-coded accent colors, blueprint grids, restrained metallic surfaces, and no manufacturer styling. A separate public-branding gate remains required before launch marketing.
