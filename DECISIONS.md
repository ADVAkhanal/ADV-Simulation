# Decisions

## 2026-08-03 - Browser-first vertical slice

Use the existing React/Vinext/Sites project for the first playable proof. It enables immediate iteration and sharing. Keep simulation state deterministic and renderer-independent to preserve a desktop/VR migration path.

## 2026-08-03 - 2D material field before 3D

Use a tactile canvas material-removal interaction rather than premature voxel/mesh CSG. The test is whether cutting, failure, inspection, and progression are fun and understandable. Upgrade rendering only after that loop earns it.

## 2026-08-03 - Working title only

Use Project Toolpath internally. Final title, logo, and public narrative remain a founder creative gate.
