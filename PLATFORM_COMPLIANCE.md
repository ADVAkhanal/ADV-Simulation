# Platform compliance

Web prototype: no accounts, payments, telemetry, user uploads, or persistent server data. Device-local progression only.

Steam backlog: Steamworks agreement and app identity, controller requirements, achievements, cloud saves, overlay behavior, crash reporting, privacy disclosure, third-party notices, content ratings, store assets, and depot/branch rollback.

Meta Quest backlog: developer organization, supported SDK/runtime, performance and thermal budgets, locomotion/comfort, tracked-controller ergonomics, boundary behavior, entitlement, pause/resume, accessibility, privacy, store assets, and submission testing.
