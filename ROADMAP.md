# Roadmap

1. Feel prototype: one contract, cut/overcut, heat, wear, breakage, inspection, scoring, retry.
2. Comprehension: tutorial timing, readable blueprint, controller support, structured playtest.
3. Spectacle: chips, coolant, sparks where physically plausible, richer state-reactive audio, camera impact.
4. Progression: workshop screen, machine/tool upgrades, three connected contracts, save migration.
5. Creator proof: shareable result card, seed-based daily challenge, contract authoring tools.
6. Desktop foundation: shared simulation package, native shell/engine evaluation, Steam demo plan.
7. VR feasibility: interaction prototype and Quest performance budget only after core-loop validation.
