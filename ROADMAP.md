# Roadmap

1. **Feel proof:** one contract, cutting, overcut, heat, wear, breakage, inspection, scoring, instant retry. Complete.
2. **Comprehension gate:** 5/5 new players start cutting in 10 seconds and can explain the blueprint rule after one attempt. Add controller support and a structured playtest script.
3. **Retention gate:** implementation complete: three contracts, three enforced tool identities, mastery grades, contract advance/retry, and v2-to-v3 save migration. The voluntary same-session retry target still requires observed playtest evidence before claiming success.
4. **Creative-code gate:** expand G//CODE Stage from three remixable programs into target challenges, incremental patterns, debugging puzzles, creator seeds, and portrait-safe replay capture.
5. **Quality-gameplay gate:** implementation complete: active characteristic selection, instrument choice, visible tolerance logic, findings, and accept/rework/scrap decisions. All dimensions remain fictionalized and clearly labeled; comprehension still requires playtesting.
6. **Shop-drama gate:** a small contract board with setup time, tooling cost, deadline, margin, downtime, and reputation consequences.
7. **Content-system gate:** data-driven contract schema, deterministic seeds, validation tooling, and a daily shop challenge. Add shareable result cards before any global leaderboard.
8. **Feel and spectacle:** physically plausible chips/coolant/sparks, state-reactive audio, haptics where available, and camera impact without reducing readability.
9. **Social proof:** asynchronous challenge codes and ghost/toolpath comparison. Consider peer-to-peer co-op only after solo retention and deterministic sync are proven.
10. **Desktop foundation:** shared simulation package, engine evaluation, controller-first UI, Steam demo plan, achievements, and cloud-save design.
11. **VR feasibility:** inspection-first OpenXR interaction prototype and Quest performance budget only after the desktop loop validates.
