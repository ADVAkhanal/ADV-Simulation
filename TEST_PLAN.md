# Test plan

Automated checks cover server rendering, game controls and copy, simulation constants, reduced-motion and responsive styling, and absence of stale manufacturing-marketing content.

Playtest acceptance for the first slice:

- A new player starts cutting within 60 seconds without developer explanation.
- The player can identify the target silhouette and feed control.
- Overcut and tool overload produce understandable feedback.
- Inspection returns a clear grade and actionable reasons.
- Restart produces a fresh deterministic contract.
- Keyboard and pointer/touch paths work.

Subjective evidence still requires founder or external playtesting; no engagement claim is made yet.
